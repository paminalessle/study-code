# Group: Jan, Manaka, Pamina

## Functional Requierments
    1. Makes a sound
    2. Time can be set by user
    3. Multiple alarms can be set
    4. "snooze" option
    5. Alarm sound can be set
    6. Vibrates with the sound
    7. The alarm can be stopped
    8. Time should be set according to the time zone

## Non- Functional Requirements
    1. The screen should be visible in the dark
    2. The system should be easy to use


## Refined Requirements

### Requirement: Make a sound
    User Level:     
    The alarm-clock makes a sound

    System Level:   
    Detects the time to make a sound
    
    Software Level: 
    Software compares current time with   set-time
